# CarbonCortex

Enterprise Coal Intelligence Platform — AI-powered quality prediction, blend optimization, and decision intelligence for coal mining operations.

## Tech Stack

- React 19 + TypeScript
- Vite
- TailwindCSS v4
- Framer Motion
- Recharts
- Lucide React
- React Router
- Radix UI (Shadcn-style components)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the application.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Landing page |
| `/login` | Authentication |
| `/dashboard` | Executive dashboard |
| `/prediction` | Coal quality prediction |
| `/blend` | Blend optimization |
| `/decisions` | Decision intelligence |
| `/simulator` | Scenario simulator |
| `/reports` | Reports & downloads |
| `/settings` | Users, roles, AI config |

## Build

```bash
npm run build
npm run preview
```
